## SNIPPET 1338 — "01 base header"

### Bloque A: Botones Dona aquí / Visítanos — color
Sección completa a ELIMINAR (pisada por snippet 1915):
```css
/* ── Botones Dona aquí y Visítanos — fondo blanco ── */

  background-color: #ffffff !important;
}

header.wp-block-template-part > div:first-child .wp-block-button__link:hover {
  background-color: #a22121 !important;
  color: #ffffff !important;

```
Motivo: el comportamiento real confirmado en el sitio es fondo rojo en reposo /
blanco en hover — exactamente lo contrario de estas reglas. El snippet 1915
es el que gana en la cascada.

### Bloque B: Header comprimido en scroll — logo/texto/botones dentro de div:first-child
Sección completa a ELIMINAR (código muerto: el snippet 1906 oculta
`div:first-child` con `display:none` al hacer scroll, por lo que estas
reglas nunca llegan a mostrarse):
```css
/* ── Header comprimido al hacer scroll ── */

    background: rgba(253, 249, 233, 0.96) !important;
    box-shadow: 0 4px 28px rgba(162, 33, 33, 0.18) !important;
}

/* Logo se achica SIN cortar */

    width: auto !important;
    height: 36px !important;
    max-width: none !important;

    transition: height 0.3s ease !important;

/* Texto HOGAR SAN JUAN APÓSTOL se achica */

    line-height: 1.2 !important;
}

/* Texto San Clemente se achica */
header.wp-block-template-part.scrolled > div:first-child p {
    font-size: 10px !important;
    line-height: 1 !important;
    transition: font-size 0.3s ease !important;
}

/* Botones Dona aquí y Visítanos se achican levemente */
header.wp-block-template-part.scrolled > div:first-child .wp-block-button__link {
    height: 26px !important;
    font-size: 10px !important;
    padding: 0 10px !important;
    transition: all 0.3s ease !important;
}
header.wp-block-template-part.scrolled > div:first-child .wp-block-button__link img,
header.wp-block-template-part.scrolled > div:first-child .wp-block-button__link svg {
    width: 11px !important;
    height: 11px !important;
}
```

**NOTA — verificar antes de borrar por completo este Bloque B:**
La primera regla (`header.wp-block-template-part.scrolled { background: ...; box-shadow: ...; }`)
aplica al header en sí, no a `div:first-child`. Como 1906 solo oculta
`div:first-child` (no el header completo), esta regla específica podría
seguir siendo visible en el borde del header. Recomendación: al editar,
elimina primero solo las reglas de `> div:first-child ...` (logo, texto,
botones) y deja la regla de `background`/`box-shadow` del header hasta
confirmarla por separado.
