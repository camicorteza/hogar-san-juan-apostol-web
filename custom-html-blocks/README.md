# Bloques de HTML personalizado

Esta carpeta guarda el código de los bloques "HTML personalizado" que viven
directamente en el editor de páginas de WordPress (Gutenberg) — separados de
los snippets de WPCode.

## Cómo agregar cada bloque confirmado en uso

Por cada bloque HTML del que estés segura que está en uso:

1. Crea un archivo nuevo aquí con el nombre: `{pagina}-{descripcion}.html`
   (ver `docs/convenciones-nombres.md` para el detalle completo del formato)
2. Pega el código HTML completo del bloque
3. Agrega el comentario de cabecera con página, URL y ubicación aproximada
